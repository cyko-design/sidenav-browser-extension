# Sidebar Nav privacy policy

Prepared November 15, 2026

Sidebar Nav adds a navigation sidebar to sites you choose. The extension reads the active tab’s address when you open its popup to identify the site. On approved sites it reads the current page address to highlight matching links and uses site colours to style the edge tab. When you click **Scan Navigation**, it reads navigation link labels, destinations and menu structure from the current page to find feature links. It filters common account and personal-content links and does not open projects, files, or conversations to collect their contents.

Sidebar Nav uses Chrome’s local extension storage for site access settings, enabled status, tab position, saved navigation labels and URLs, and the time of the last scan for each site. The extension has no analytics, tracking, advertising, cloud sync, or remote processing. Sidebar Nav does not transmit this information to its developer or third parties. If you click a link, Chrome opens the destination as it would for a normal website link.

**Clear Saved Navigation** removes the current site’s scanned links and timestamp after you confirm. **Remove Site Access** stops Sidebar Nav on that site and keeps the saved links and preferences. Uninstalling Sidebar Nav removes its local extension storage.

Sidebar Nav’s use of information adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

For privacy questions, use the contact details listed on Sidebar Nav’s Chrome Web Store page.
