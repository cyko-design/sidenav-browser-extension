# Chrome Web Store listing

## Store fields

| Field | Value |
| --- | --- |
| Name | Sidebar Nav |
| Version | 0.5.0 |
| Language | English |
| Category | Workflow & Planning |
| Short description | Open a left-edge navigation sidebar on sites you choose. Scan for feature links and save them on this device. |

## Detailed description

Sidebar Nav adds a collapsible navigation sidebar to websites you choose. Use the tab on the left edge to open the sidebar, and drag it up or down to put it within reach. The website’s original navigation stays available.

Choose **Allow Site Access** for the website you’re on. Then use **Scan Navigation** to read the current page’s navigation labels and links and save supported feature links in the sidebar. Sidebar Nav groups links when it can identify their sections. Higgsfield also has a built-in navigation list. Scan results vary with each site’s menu structure.

Sidebar Nav reads the current tab’s address to identify the site and highlight the current section. Each site’s saved links, preferences, and last scan timestamp stay on your device. Scans run when you click **Scan Navigation**. There’s no analytics, advertising, cloud sync, or remote scanning.

Use **Clear Saved Navigation** to remove discovered links and reset the scan timestamp. Use **Remove Site Access** to turn off the sidebar for that site while keeping its saved links and preferences.
